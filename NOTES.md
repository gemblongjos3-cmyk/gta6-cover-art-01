# Notes — Vice Coast Cover Studio

Vice Coast Cover Studio is a browser-based cover-art builder for the GTA6-style
"Vice Coast" entry: a canvas renderer that composes a poster-style cover from
layered art, lettering and a preset color grade.
It ships an in-page editor for tweaking layers, text and typography plus
several "shot modes" that frame the result as different capture variants.
A small build/bundle tool packages the renderer and assets into a static
output, so the final cover can be produced and screenshotted without a server.
